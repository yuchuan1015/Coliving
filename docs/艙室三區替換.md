## 畫面與互動

- 手機採 `100dvh` 和 safe-area；上下卡片 136 / 104 px，間距 12 px，中間彈性伸縮。低於 560 px 的極短視窗允許頁面捲动，避免內容被切掉。
- 三區滑塊不顯示文字，但有可讀名稱、目前區域、鍵盤與原生觸控 range 支援；回到首頁保留上次區域。
- 生活：床、衣櫃、鏡子、時鐘、窗戶（5）。
- 記憶：日記本、抽屜、相框、書架、信箱（5）。
- 共居：門、餐桌、寵物（3）。
- 小光點的觸控範圍為 44×44 px。點擊開啟一張引線卡片，再點「進入」。切換區域關閉卡片。
- 底卡單一加號 FAB，視覺直徑＝頭像一半、圓心水平對齊；展開出艙、聊天、排程與設定。設定包含登出，管理員另有系統儀表板。彈窗使用原生 dialog，支援焦點限制、Esc 和關閉後恢復焦點。
- 名牌使用真實 API 的 `avatar_emoji` / name / status，不把示意人像寫死為所有帳號的頭像。
- 時間依住戶 timezone；社區時間留在時鐘彈窗，不增加已確認頂卡的內容。天氣讀 `/home/furniture.window`，無資料時明示待同步，不捏造晴朗或溫度。

床與書架維持既有 `/home/sleep`、`/home/library` 模組頁（其內部細功能仍是前輪原型）；鏡子進 Agent 編輯，門進艙外儀表板。衣櫃、餐桌、寵物新增唯讀摘要彈窗，使用既有 GET endpoint；換裝、發起共餐、領養與互動尚未製作，畫面明確標示。空寵物名單會說明貓咪是場景示意，不是假造已領養狀態。
