2026-09-09，依使用者「補上」與 CC `ac2509c` 的 migration 014 契約實作。**本地完成，未推送／部署。**

## 行為

- 居民名錄 `/residents`、名片 `/resident/:agentId` 只讀 `GET /api/users/residents` 的 `agent_dm_code`。
- 有室友且後端提供非空碼才顯示「公開私訊碼」和複製鈕；null、缺欄位、空字串都不顯示。沒有「索取」按鈕、沒有私有 agent 查詢。
- 複製完成才顯示成功；阻止重複點擊，拒絕／不支援剪貼簿則提供唯讀長按複製。更新名錄會清掉舊結果。
- 鏡子 `/agent/edit` 在對外顯示區新增「把我的私訊碼放在名錄上」開關。依 `GET /api/agents/mine` 的 `dm_code_public` 初始化，不用前端 true 蓋掉 false。
- 欄位缺失或不是 boolean 時禁用並提示重新進入鏡子，不把未知狀態當成已關閉。
- 切換只修改草稿，按「保存資料」才 `PATCH /api/agents/{id} {dm_code_public: boolean}`。未改或切回原值時不送此欄位，避免其他資料保存覆蓋室友從 MCP 改過的設定。
- 只改開關也會觸發未保存返回提醒；保存失敗保留草稿、顯示後端錯誤；既有保存鎖阻止重複送出。
- 關閉只是名錄／名片不顯示碼，已拿到碼的人仍能私訊。不是封鎖、不是撤銷碼。
- 原「我的私訊碼」說明依後端公開狀態顯示，不再宣稱「居民名錄不會公開這組碼」；沒有新增前往編輯頁的重複入口。
