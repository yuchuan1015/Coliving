# 唯讀家具與郵驛

日期：2026-09-10。狀態：使用者批准連同繁簡版本一起修改、推送與部署；前端完成，待發布驗證。

## 契約與介面

- 依 master `2f73f0e`：日記保留列表、搜尋、展開閱讀；移除新增、修改、刪除及對應 API helper。讀取失敗可重試，舊搜尋的遲到回應不覆蓋新結果。
- 抽屜顯示上鎖、物件數量與後端 message，不顯示標題／內容／列表、不提供任何存取按鈕。adapter 只接受 locked=true、非負安全整數 count、字串 message，再建立只含這三欄的新物件；即使誤回 items 也不保留。未知／錯誤回應仍上鎖，數量顯示讀取失敗而不是 0。
- 艙室信箱保留收件匣／寄件匣；公共郵驛保留收件匣／寄件匣／已送達定時信。移除寄信、定時寄送、刪信、收件人選單與寫入 API helper。
- 信件內容只在使用者點選後 GET；寄件匣也能讀自己已寄出的信。後端既有 GET 閱讀標記契約不變，未讀數仍可更新。切換分頁／卸載後遲到的詳情不能重開舊信；初始載入失敗不能透過切分頁偽裝成空信箱。
- 依 master `a6852f5` 傳達的使用者新決定：撤下「實體寄送」專用入口與管理員物流 PATCH 表單。既有 physical 信件仍可在一般收寄件匣閱讀，保留狀態文字，不刪資料；MCP order_physical／後端 PATCH 的撤除交 CC，前端正式上線後另留言通知。
- 舊 `/field-preview/mail.html` 靜態書籤導向真正的 `/mail`，不再載入舊 demo 寫信介面。其他場域原型不變。
- 導覽手冊與艙室錨點說明同步唯讀／上鎖界線；正常信件的寄送／定時信／刪信交由室友使用 MCP，實體寄送目前不提供。報錯郵箱與 mailto 草稿不受影響。

## 保留的內容

- 紫黑風格、三張艙室卡片、寫實圖片、家具入口、相簿與鏡子等其餘功能不變。
- 繁體／簡體切換一併保留。已移除過時操作文案並重建目前 1669 筆介面字典；居民姓名、日記、信件及其他使用者內容不轉字。
- 不修改 backend、資料庫、nginx、MCP、服務；沒有為測試讀取真人私密資料、發信、刪信或呼叫模型。

- 252 項本地非瀏覽器合約／配色測試通過；包括兩種語言、兩種角色、唯讀按鈕邊界、抽屜隱私／壞資料、空值與載入失敗區分、重試、遲到回應、舊郵驛入口轉向。
- production／album-preview TypeScript、修改檔 oxlint、字典一致性、git diff --check、Vite／PWA build 通過。主包大於 500kB 為既有警告，未隱藏。

- 發布會先核對 source HEAD 與乾淨工作區、完整備份正式 dist 並驗證 SHA-256。只部署 `/opt/coliving/frontend/dist`，保留舊 assets，不重啟服務，權限設 755。
