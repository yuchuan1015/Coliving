# 菜園收購前端

2026-09-11。前端 `codex/ui-chrome`，依後端接手任務轉達的本版範圍完成；**僅本地實作與驗證，未推送、未部署**。後端對接候選為 `codex/garden-economy` / `f3df80e`。信用與貝的首頁展示已於上一批發布；本文件描述的是尚未發布的收購功能。

## 本版範圍與入口

- 入口沿用 `/home/garden` →「雙方倉庫」，不增加新的公共場域。
- 私人菜園原有紫底、綠色點綴保留。兩個倉庫各自展示收成、後端整份售值及自己的貝；收成的精確分數沿用預設收合、點擊展開。
- 人類在自己的作物下選「全部數量／部分數量」，輸入克數 →「取得報價」→ 檢查數量與售值 →「確認出售」。表單就地展開，只有最後確認才送出售。
- 室友倉庫唯讀，可以看售值；室友由 MCP 自行出售。網頁不能代售室友的收成。
- 不做全倉出售、選種收益預估、浮動行情或新的消費規則。

## 接線

| 用途 | 介面 | 傳入欄位 |
| --- | --- | --- |
| 讀取兩方倉庫售值 | `GET /api/garden/market` | `owner=user|agent, limit=100, offset` |
| 取得人類收成報價 | `POST /api/garden/market/quote` | `crop_id, quantity_g` |
| 明確確認／重試同筆出售 | `POST /api/garden/market/sell` | 上述兩欄 + `quote_id, request_id` |

網頁不傳價格、owner、actor、user_id、agent_id 或自訂時間。`_expectedUserId` 只留在 Axios 的本地設定，不在 POST body、query 或 header 中；用來確認實際 access token 的 `sub` 仍是畫面所屬居民。這項本地檢查不代替後端 JWT 驗證與權限。

## 數量與帳目

- 輸入只接受正數 ASCII 整數、小數、分數，完整字串最多 128 字元，不用浮點換算。貼上過長字串會阻擋報價，不偷偷截斷成另一個量。
- 使用 BigInt 分數比較庫存、輸入與報價。正規化回應可以比輸入長；出售仍送原本有效的輸入字串，不改送變長的回傳分數。
- 所有收入與售值都取後端欄位；前端不計算每克售價、不重新配批次。顯示值為 0.00 的微量收入仍可查看非零精確值。
- 同作物整份庫存若精確字串長度超過可提交範圍，明確提示暫不能整份出售，不做截斷或近似處理。
- 不可核對來源的收成無售出入口，也不補假價格。404／503 保留原倉庫呈現並提示收購暫未開放，其他菜園功能不依賴 market。
- 成功後重新讀取 market，並請父頁重新讀取原庫存；不把售出回執的舊餘額覆蓋現在錢包，不在前端累加貝。

## 未確認出售與身分保護

- 確認前先把不可變的四欄請求存入本分頁的 `sessionStorage`，依居民 ID 分隔；不存 token、錢包或售價。
- 同步鎖防連點；網路錯誤、5xx、無法解析的 200、未知 4xx 都保留原請求。其他出售先鎖住，只能明確重試同一筆、同一 request_id。
- 確定是出售業務回應的 409 `stale_quote`／`insufficient_stock` 才清除該 pending，重讀庫存並要求重新報價和確認。`idempotency_conflict` 不另換 ID 繞過，保留記錄並提示聯絡客服。
- 原 pending 即使重新讀 market 失敗仍能重試 sell；成功回執不需要售值 GET 可用才能確認。
- 切分頁、頁面重新掛載可還原本分頁 pending，不會自動送出。離開前請先確認結果；`sessionStorage` **不是跨瀏覽器或關閉分頁後永久保存的交易帳本**，本版不另建跨裝置 outbox。
- 取消只取消尚未出售的報價；送出中的 sale 不能被取消按鈕解鎖。舊報價、舊身分的 refresh 及晚到結果不能取消或覆蓋新讀取。
- Axios 的新 guard 僅在明確帶 `_expectedUserId` 的請求啟用。請求前、成功／錯誤回應、refresh 後及排隊重放都核對實際身分；跨分頁換帳號不會把舊出售錯誤當作原居民的終局結果，也不覆寫新帳號 token。一般舊端點不新增 JWT payload 檢查要求。

## 本地隔離預覽

`frontend/scripts/garden-market-preview/index.html` 使用實際倉庫元件與明確的合成 gateway，無真帳戶或網路交易。現有 Vite 啟動時可開：

`http://127.0.0.1:5193/scripts/garden-market-preview/index.html`

`?case=fractions|unknown|stale|denied|unavailable` 分別演示分數、成功但遺失回應、過期報價、權限失效、尚未發布。每次重新整理分配獨立範例身分、重設記憶體資料；`unknown` 請在同頁按重試確認不重複扣菜。舊 private-garden preview 未提供 market gateway 時直接使用本地 unavailable gateway，不會退回正式 API。
