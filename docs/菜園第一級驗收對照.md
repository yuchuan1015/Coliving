# 菜園第一級後端驗收對照

2026-09-11。依正式 `backend/data/garden/tier1-v1/acceptance.json` 的12種生命週期＋22共同案例執行。本機服務驗收使用真SQLite資料表、真service交易、伺服器時鐘、實際生長/照顧/偷取/採收及倉庫帳本。12種基準不替換作物卡、不塞成熟批；資料檔由catalog SHA-256檢查後載入。

基準情境只固定季節係數為1、隨機問題不發生，沿種植起點每6個現實小時呼叫真care；成熟門檻以Fraction計算並向上取至微秒。一般季節、實際隨機雜湊、照顧惡化和兩個完整多年生周期另由 `test_garden_engine.py` 驗證。

## 併發、重試、重啟和交易中斷

`backend/tests/test_garden_concurrency.py` 的6個測試使用實際磁碟SQLite，每個worker獨立Session/連線，以barrier同時起跑。

| 測試 | 實際驗收 |
|---|---|
| `test_simultaneous_theft_and_harvest_conserve_exactly_one_batch` | 偷與收同時競爭；結果只可能user0＋agent200或user100＋agent100，合計200。 |
| `test_two_distinct_theft_requests_allow_only_one_credit` | 不同request同時偷，僅一次成功、只入庫100g。 |
| `test_same_request_concurrent_retry_returns_one_effect` | 同request兩次皆回結果，但只有一筆effect/receipt；相同key不同操作拒絕。 |
| `test_multiple_tick_workers_do_not_duplicate_public_shares_or_clear_votes` | 兩個tick worker同時跑，三人各200/3g，只3筆公田入帳，不提前開新投票。 |
| `test_restart_retains_inventory_batch_identity_and_idempotency_receipt` | 關閉所有Session/engine再建連線，倉庫、批ID、偷取資格與receipt仍在；舊request不重發。 |
| `test_credit_write_failure_rolls_back_batch_ledger_and_receipt_atomically` | SQLite寫garden_stock時注入故障，批次/帳本/receipt全部rollback；恢復後同request可成功一次。 |
