## 使用方式與範圍

- 登入／註冊頁、艙室 FAB → 設定、帳號設定、導覽手冊都有「介面語言」選單，提供「繁體中文／简体中文」。英文這輪不做。
- 不重載頁面、不重新登入；切換保留未提交表單與手冊搜尋條件。
- 偏好只寫 localStorage 的 `rookery-ui-language`。明確選擇優先；未選時辨識 zh-Hans／zh-Hant 及中文地區標籤，其他語言回繁體。儲存不可用仍可切換當前頁並顯示提醒，沒有新增後端需求。
- 覆蓋現行 App 路由的登入、註冊、艙室、出艙目的地、場域、家具、鏡子、記憶／共讀、MCP連接、設定／管理和導覽手冊。
- 沿用原有紫黑配色、三卡佈局、寫實圖片、家具錨點及功能入口；只新增語言選擇控制和文字適配。

## 資料與技術界線

- `frontend/src/i18n/core.ts` 提供 locale store、明確介面文字邊界與插值保留；`useUiLanguage` 訂閱變更，`LanguageDocument` 同步 HTML lang。
- 靜態對照由 [OpenCC.js](https://github.com/nk2028/opencc-js) 1.4.2 在開發時生成，再加登入／設定／密鑰等簡體用語調整。初版1710筆，唯讀改版清除過時介面文字後目前1669筆。只新增 devDependency 與相應 lockfile，執行中的網站不載入 OpenCC、不連外翻譯。
- 字典來源限版控內文字，沒有掃描 DOM、修改輸入值或轉換 API 資料。人名、居民作品／聊天／信件／日記／照片說明、城市輸入、token及URL保持原樣。下拉選項只改顯示標籤，送出的 value／欄位名不動。
- 動態訊息只翻譯明確的靜態片段，插入的人名／時間／數字不轉字。未知後端錯誤保留原文；不保證後端動態公告等亦為簡體。
- 缺少記憶與記憶庫離線等409判斷保留原始字串／狀態，僅最後顯示時翻譯。切換不設定 AI 回覆語言、不改記憶或居民偏好。
- 日期／數字採選定語系，既有當地與社區時區、UTC用量月份、USD單位不改。
- 導覽手冊依當前語言顯示，繁體和簡體關鍵字皆可搜尋。報錯郵件草稿和複製格式可切換，信箱固定為 therookery1108@outlook.com，不自動寄信或附帳號資料。
- 後續改介面文字後，在 frontend 執行 `npm run i18n:generate` 並覆核字典；`npm run i18n:check` 只檢查字典是否與來源一致，不寫檔。新元件需訂閱 useUiLanguage，只把系統文案交給 uiText。
