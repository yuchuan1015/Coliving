## 已完成

- /agent/advanced 的 MCP 區塊改成鑰匙清單：GET /api/agents/mine/mcp-tokens，每把顯示 label、建立時間、最後使用、作廢狀態。
- 兩顆複製鈕分別照回應的 connect_url／claude_code_cmd 原值；不自行拼 token、不更改指令。不是只顯示一次。
- POST /api/agents/mine/mcp-token {label}：名稱去首尾空白、非空最多32字；成功立即加入清單，防連點，不自動重試產生。結果不明提示先更新清單確認。
- DELETE /api/agents/mine/mcp-tokens/{token_id}：兩段確認；成功立即丟棄該把 mcp_token／connect_url／claude_code_cmd，其他鑰匙不變；失敗顯示 detail。
- 領養 POST /api/agents 的 API key 選填，空白省略 api_key；成功顯示 first_key 連接器網址和複製鈕，不直接跳聊天，提供返回艙室／查看鑰匙清單。
- first_key 缺少時引導去鑰匙清單，不叫住戶重新領養。
- 剪貼簿拒絕或缺少 API 時提供唯讀手動複製；只有寫入剪貼簿成功才顯示已複製。
- secret 僅留元件記憶體，不進 storage／log／路由 state／網址列；沒有可點擊的 secret 連結、自動開啟或嵌入。只有主動點複製才進系統剪貼簿；頁面提醒不要公開或截圖分享。
