- `/home/garden` 為登入保護內的獨立私人頁；入口位於艙室 Agent 卡片右下 FAB「私人菜園」，手冊也有介紹與連結。
- 沿用原菜園溫室圖；艙室紫黑底、綠色點綴。不改三張艙室卡片尺寸、家具錨點或公共場域藍色。
- 四塊私田各 2.5 坪總面積，當中 6 m² 有效種植；產量由後端按整地計算，前端不再乘面積。
- 三個分頁：我的田地、雙方倉庫、作物圖鑑。
- 待處理成熟批次優先；已採收／失敗歷史批次與照顧紀錄預設收合。
- 同批修正 `/frontier`：移除下方重複據點資訊卡，只保留上方滑動卡；「前往農田 →」為卡片內真正的導航按鈕。圖片、公共配色、四據點滑動保留；規劃中據點沒有假入口，非目前投影片的入口不可取得鍵盤焦點。

## 正式接線

既有 authenticated API：`GET /api/garden/private`、`GET /api/garden/inventory`（owner、limit、offset）、`GET /api/garden/progress`、`POST /api/garden/actions`。本輪不需新增後端 endpoint。

- 使用者只能澆水、逐批偷菜、發起／回覆共同挖除。没有 Agent 種植、採收、照顧、施肥、代同意或時間快轉按鈕。
- 每筆 action 包含獨立 request_id 和服務給定的 opaque plot／planting／batch／proposal ID。HTTP 200 仍逐筆解讀 ok/error。
- 不明結果只重試原 ID／原 payload 的未知子集；新操作暫停。每次操作後重新 GET 田地、雙倉、圖鑑；不把 idempotent replay 的舊 plot 當最新狀態。
- 單筆 action_forbidden／403 是該筆業務拒絕，不清掉同批成功入倉。真正登入／身份拒絕清掉可操作私田；agent_required 引導返回艙室先有室友。
- 身份 generation／effect epoch／AbortController 隔離遲到回應、帳戶 A→B→A 和分頁；不持久化遊戲資料。
- 自己提出的挖除只能等候或撤回；室友提案可拒絕，接受必須明確勾選並按確認。拒絕／撤回保留作物，同意完成看 cleared:true 並刷新為空地。照顧歷史 consent_clear 中性顯示「回覆挖除提案」。
- 倉庫數量使用 BigInt 分數運算顯示 g／kg，精確值可展開；不以 parseFloat 改寫帳本，極小正数不顯示為 0。
- 農園虛擬日曆固定以 UTC 展示，真實事件使用住戶時區。圖鑑首收基準由既有 timing／time_multiplier 換算，明示不是目前田地的成熟倒數。
- 第一級 12 張讀 API，後續 60 張由核實的全球參考資料取展示欄位，明示未開放；第一級只有室友私田正數採收增加進度。解鎖進度不等於後續級別已可種植。
- 繁簡字典只收錄系統固定名稱／文案，居民提案原文、ID、數量不轉換。

## 驗證

本機 TypeScript（正式及隔離預覽）、修改檔 oxlint、396 項非瀏覽器契約／配色測試、2233 條字典一致性、Vite／PWA production build 通過；既有主包大於 500 kB 警告仍在。測試／fixture 模組未進正式 bundle。開荒入口新增單卡、可用入口、滑動、非目前投影片焦點、圖片失敗與繁簡切換檢查。

農田協作窗口用 Codex IAB 在獨立本機預覽核對：

- 390px：澆水、成熟偷菜後 2.637kg 即時入使用者倉、田裡餘 2.637kg、Agent 倉與圖鑑不誤增加。
- 原因／勾選／明確送出；自己提案等候與撤回、拒絕室友提案、接受後空地且已入倉保留。
- 回應遺失後確認原操作，不重複入帳。
- 320px：分數顯示、極小份額、載入更多；无橫向溢出。
- 1280px：四地並排、production_complete 留株可澆水、紀錄預設收合；無橫向溢出。
- 最末輪：無室友正確引導返回艙室且不洩漏私田；室友正數採收後圖鑑 1/12；第 6 級恰 12 張參考卡，320px 圖鑑無橫向溢出。全新四田單頁載入的 console warning／error 為空。

隔離 harness 開發熱更新時曾出現 createRoot 重複訊息，全新載入未重現；不等同正式網站錯誤。完整獨立驗收紀錄由農田協作窗口保存在其 handoff/private-garden/驗收紀錄.md。

以上是隔離前端驗證，不是 Safari 真機、正式住戶端到端或實際後端寫入測試。本機網址與 case 詳見 `frontend/scripts/private-garden-preview/README.md`。
