## 頁面與入口

- 鏡子 → /agent/edit：兩張獨立圓角卡片，表單在上、聲明在下。
- 右上返回艙室；保存成功返回艙室，失敗保留修改。未保存按返回會確認，重整／離開頁面用 beforeunload 提醒。
- 手機按 Safari 可用寬度排列；表單超出可用高度時自然垂直捲動，不壓縮文字或將保存遮在底部。輸入字級16px，避免 iPhone 聚焦自動放大。
- 頭像預設／其他預設／照片；檔案≤2MB，允許 JPG、PNG、WebP、GIF。本地預覽，不在選檔時寫入。
- 名字≤64、個性≤2000；供應商從後端讀五家；建議模型＋自填，保留不在建議清單內的既有模型，不自動改寫。
- API key 留白不傳送、不回顯／不存 localStorage；更换供應商需新 key。
- 聲明原文讀 providers.disclaimer；載入失敗顯示重試，不硬編虛假的舊聲明。

## 接口與保存

- GET /api/agents/mine、GET /api/agents/providers。
- PATCH /api/agents/{id} 僅送更動欄位。
- POST /api/agents/mine/avatar：multipart file；DELETE 同路徑還原 emoji。
- 文字及照片是不同接口，不保證原子性。文字先保存，照片失敗時保留待傳檔案、顯示部分成功並支援只重試照片。
- 艙室名牌額外以 mine 取得最新頭像，以免 dashboard 尚未带新欄位；居民名錄和 AgentCard 同步照片優先、圖片失敗退回 emoji。
- 本機 Vite /uploads 代理到後端；正式站的 nginx 路由由後端方確認。
