## 已完成

1. 一般聊天 `/chat/:agentId` 右上角加「用量」原生 modal。關閉鈕、Escape、點遮罩均可關閉，關閉後恢復原焦點；面板可捲動並避開安全區。
2. `GET /api/chat/{agent_id}/usage` 懶載入：點開、明確重讀、面板已開時新回覆完成才讀取。不輪詢、不呼叫模型、不新增 /usage 聊天指令。關閉取消請求、丟棄暫存；讀取失敗清掉舊金額並可重試，聊天不受影響。
3. 分開顯示目前上下文（最近一次輸入）、本次消耗（最新 reply batch）、整窗累計、此室友 UTC 本月累計。前端不按時間猜批次、不算容量百分比、不重算 token 或費用。所有價格均依後端，沒有寫死單價。
4. null 顯示「未取得」，0 保留 0；usage_partial 顯示「用量不完整 · 已知小計」，cost_partial 分別顯示費用不完整；未知模型價格完全不顯示金額。USD 最多六位小數，不把一百萬分之一美元四捨五入成 0。無效或舊格式回應顯示無法讀取，不假造完整數字。
5. 精確記憶不足 409 改至 `/agent/edit#editor-note`，鏡子讀好後一次定位並聚焦「給室友的話」，不自動寫入；外部記憶庫連不上維持原錯誤並說明不用重寫記憶，其他 409 不混用引導。首頁頭像、名牌仍不可編輯；鏡子依然是正常入口。
6. 上傳 400／413 顯示 server detail 的既有行為補齊回歸測試；檔案和說明保留、沒有自动重試或清空草稿，頭像重試只做尚未成功的步驟。
7. 聊天載入失敗可重試；拒絕讀其他室友的訊息；送出 single-flight；中文選字 Enter 和 Safari keyCode 229 不誤送；換室友／離頁後遲到回覆不插進新對話；用量面板開啟時不搶輸入焦點。

## 本地預覽

沿用既有 Vite 5186 及預覽分頁。mock adapter 攔截全部 API，不使用正式 token 或真人內容。

- 入口：`http://127.0.0.1:5186/scripts/album-preview/index.html?page=chat`，點右上「用量」。
- 情境：`&usage=unknown|known|partial|empty|zero|error|memory|offline`。上方選單可切換；記憶情境在送出範例訊息後顯示錯誤與引導。
- 固定範例數字與固定聊天回覆都明標本地示範，不能作為正式費用或真人驗收依據。
- 預覽 HTML 和新元件的本地 HTTP 均為 200；開啟面板工具回 queued，未聲稱使用者已看到。
