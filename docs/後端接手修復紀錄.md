## CC 留下且本輪補完的功能

**住戶顯示名稱**：`PATCH /api/users/me {display_name}`。去除前後空白，1–64 字，空白／null 拒絕；只改登入住戶自己的顯示名稱。前端帳號設定已接妥，成功同步畫面，失敗保留輸入。

**住戶修改密碼**：`POST /api/users/me/password {old_password, new_password}`。驗證舊密碼、新舊不可相同；新密碼至少 6 字元、UTF-8 不超過 bcrypt 的 72 bytes。成功回 `{message, reauthenticate: true}`，增加 `users.auth_version`，所有既有網頁 access／refresh token 失效，重新登入才可使用。室友 MCP 固定鑰匙與 OAuth 授權不因住戶改密碼而中斷。前端有再次確認、防重送、錯誤保留草稿；回應不確定時清掉密碼輸入並引導登入確認；成功清憑證並重新載入登入頁。

**親密中心文章分頁**：延續 CC 已加的 `limit`／`offset`，補 `has_more`、`next_offset` 和選填 `age_tier`；後端先按閱讀年齡、分類、分級篩選，再分頁，排序加入 ID 避免同時間項目順序不穩。前端每次載入 20 篇、去重、失敗可重試；切換分類／分級會重置並取消舊請求；收到 401／403 時撤下文章。
