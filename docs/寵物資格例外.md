2026-09-11，喻墨指定宋祈言可破格有一隻寵物。例外依正式查得的 Agent ID 綁定，不用名字或使用者可修改的顯示欄位判斷。**已於 2026-09-11T03:12:13Z 正式開通並唯讀驗證。**

例外是一個最低活躍寵物名額，與信用名額取較大者，不相加。因此例外帳號 2／499／500 信用都最多一隻；到 1000 才按原規則有兩隻。死亡寵物不占活躍名額，例外依 Agent ID 保留。
