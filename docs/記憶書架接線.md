## 入口

艙室「記憶」區 → 記憶書架 `/home/library`，分成兩個入口：

- 我的記憶 `/memory`：住戶的 mem0 記憶庫。
- 一起讀書 `/reading`：住戶與室友的私人共讀；書籍頁 `/reading/:bookId`。

公共圖書館不混用。艙室比例、家具位置、其他卡片及 FAB 沒改。頁面使用既有登入 token，不寫入示例內容，不將書籍、批注、記憶另存 localStorage。

## API 與互動

已讀 origin/master 39d27db 的 memory / reading router 及 service；呼叫集中於 frontend/src/api/bookshelf.ts。

| 頁面 | 接口 | 行為 |
| --- | --- | --- |
| 我的記憶 | GET /api/memory | 列表時間倒序，住戶當地時區；空列表與重試 |
| 搜尋 | POST /api/memory/search | query、limit=50；按搜尋才提交，取消過期回應 |
| 新增 | POST /api/memory/remember | text ≤5000；成功重新讀列表，允許 mem0 整理摘要 |
| 刪除 | DELETE /api/memory/{id} | 確認後送出；不按文字猜 ID |
| 匯出 | GET /api/memory/export | format=json 或 markdown，後者解開 JSON 的 content 再下載 |
| 私人書架 | GET /api/reading/books | 真實進度、劃線數、批注數 |
| 貼文上架 | POST /api/reading/books | title、author?、text、source_format=txt |
| 檔案上架 | POST /api/reading/books/upload | file multipart；title/author query；按上架才上傳 |
| 閱讀 | GET /api/reading/books/{id}?page=N | 不給 page 續讀；分頁由後端決定，使用絕對 paragraph idx |
| 劃線 | POST /api/reading/books/{id}/highlights | 同段選字2～2000字，paragraph_idx、text |
| 批注 | POST /api/reading/books/{id}/notes | paragraph_idx、content≤4000、highlight_id? |
| 移除標註 | DELETE 對應 highlights/{id} 或 notes/{id} | 只提供刪除自己的標註；先確認，刪線保留批注 |

選檔支援 txt/md/markdown/text，最大4MiB，最多200萬字／50本依後端限制。失敗保留輸入，請求期間阻擋重複送出；成功才更新列表或清空表單。記憶 400（自管記憶）、403（無室友）、503（社區 mem0 未開）有明確提示且停用寫入／匯出。

## 特別處理

- 搜尋目前只回 text/score，沒有 id/時間，所以搜尋結果不能刪；回完整列表再刪。
- 閱讀 GET 本身會寫最後閱讀頁：不做背景預讀。頁面切換取消過期前端回應，翻页成功後後端已記錄進度。
- highlight 無起訖 offset，相同原文出現多次會一併標示，選字時提示；重疊的人／室友標示保留兩種顏色。上傳內容當 React 文字，不執行 HTML。
- 不加入舊 OB 的 ob_enabled 開關，進階設定不在本次範圍。
