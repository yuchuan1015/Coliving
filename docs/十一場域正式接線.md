## 出生年

- 艙室 FAB 的設定彈窗加入一次性出生年補填；場域 403 可以前往 `/settings` 補填後返回導航。
- `GET /users/me` 值為 null 才提供補填；已有值唯讀。undefined 是資料未同步，先 GET 重讀，不等同 null。
- 輸入 → 檢查 → 明確確認不可更改 → 單次 `PATCH /users/me {birth_year}`。送出期間鎖輸入、關閉與其他操作；失敗保留值，重新讀取只做 GET。
- 註冊補原本缺少的必填出生年，並傳瀏覽器 IANA 時區；不新增或代填重要日期。
- 登入／註冊成功後補 GET 完整帳號。若補讀失敗仍保存成功的登入結果，不誤報帳號建立失敗／消耗第二次邀請碼；出生年編輯保持鎖定直到完整資料回來。

## 共用行為與安全

`src/fields/fieldData.ts`：場域資料、UTC→Asia/Taipei 時間、URL、取消／重試讀取。舊 UTC 字串若沒有 offset，依 API 的 UTC 契約補 Z。切分類、重試或失敗不沿用前一筆／前一分類的資料，更不退回 mock。

`src/fields/shared.tsx` / `fields.css`：同一套頁頭、寫實背景、分類、空狀態、錯誤、詳情彈窗、表單。35 項回呼／資料測試驗證送出鎖與保留輸入；刪除、啟用、發起遊戲等需明確操作。HTTP 成功後只重讀，不自動重送。原本 JWT client 的 token refresh 策略不變。

文章和留言當文字渲染，不插入來源 HTML。展品與佐證連結限 http(s)，外連使用 noreferrer；作品 HTML 只進 sandbox iframe，不進宿主 DOM。iframe 不允許腳本、同源、表單，CSP 限制外部素材；不把它說成完整的網路隔離環境。

微瀾 16 種動作按後端 `legal_actions` 建表單：五子棋點格只選取，確認才落子；換牌 0–4 索引最多三張；麻將只送本人 raw tile；投票／夜間動作只送 choices 中的目標。勝負與私有資訊完全由後端決定，前端不推算、不暴露未回傳的其他玩家手牌。桌况手動更新，不用背景重讀打斷輸入。
