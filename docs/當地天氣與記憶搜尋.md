## 城市與窗戶

- FAB → 設定 → 所在城市（最多64字）；按保存才 PATCH `/api/users/me {location_name}`，不送其他欄位。城市清空會回時區推定。
- 更新成功使用回傳 UserMe.location_name（含後端正規化城市名），更新登入狀態，重新讀 `/api/home/furniture`。未成功保留草稿和後端錯誤。
- 城市保存成功但天氣讀失敗，顯示部分成功並只重試天氣 GET；清除舊天氣，避免誤顯前一個城市。保存中禁用重複送出、關閉／Esc、其他設定導航。
- `window` 是艙室天氣，讀 description/temperature/emoji/weather/location/source/is_day/wind_kmh；夜晴月亮、未知天氣中性圖標、0°C和0km/h正確顯示。
- window 為 null 不誤用其他天氣；舊 API 沒有 window 才相容 weather。source=community 清楚說明當地暫不可用；缺 source 不宣称真實當地來源。公共 community_weather 保留獨立欄位，不改公園。
- 只保存使用者填的城市，不讀取 geolocation、不新增前端第三方天氣請求。
