## 給 Codex（共居窗寫）

- 2026-09-08 **「我的記憶」頁面**（她要的）：一個新頁面讓住戶管理 mem0 裡的記憶。API：`GET /api/memory` 全部、`POST /api/memory/search {query, limit}` 搜、`POST /api/memory/remember {text}` 手動寫、`DELETE /api/memory/{id}` 刪、`GET /api/memory/export?format=json|markdown` 匯出。有自帶記憶 MCP 的住戶回 400；社區沒開 mem0 回 503。建議頁面：列表時間倒序＋搜尋＋刪除＋匯出＋手動輸入。路由 `/memory`。
- 2026-09-07 **聊天頁會收到 409**：室友還沒有任何記憶（沒相框、沒日記、沒抽屜、沒記憶 MCP）時，`POST /api/chat/{agent_id}/messages` 回 409 `{"detail":"還沒讀到記憶"}`，人的那句不會被存。前端把它顯示成一句話（怎麼顯示她待定，先照 detail 原文），並引導去相框放東西。室友設定頁「外部 MCP」旁邊加「這個是我的記憶」單選＋「recall 工具名」欄（`PATCH /api/agents/{id} {memory_mcp, memory_recall_tool}`）。
- 2026-09-07 **鑰匙有名字了**：室友設定頁「MCP Token」那塊改成清單——`GET /api/agents/mine/mcp-tokens` 列出每把（label、建立時間、最後使用），「產生」時要填 label（≤32 字，`POST /api/agents/mine/mcp-token {label}`，回傳的 `mcp_token` 只顯示這一次），每把有「作廢」（`DELETE .../mcp-tokens/{token_id}`）。管理頁活動時間線每筆多 `bed_label`，顯示在動作旁邊（例「CC 主窗」「站上」「網頁」）。日記來源多一種 `bed`＝「外接床位」。
- 2026-09-07 **時區（她定）**：艙室（我的家）頁面除了「社區時間」那一欄，全部用住戶當地時間顯示；公共場域（廣場、公園、圖書館…）一律用社區時間＝Asia/Taipei。API 的時間戳都是 UTC（帶 +00:00），**轉換在前端做**。要接的：(1) 註冊時用 `Intl.DateTimeFormat().resolvedOptions().timeZone` 自動帶 `timezone` 欄；(2) `GET /api/users/me` 回 `timezone` 和 `clock {utc, timezone, local_time, community_timezone, community_time}`，艙室時鐘用 `local_time`，加一欄「社區時間」用 `community_time`；`GET /api/home/furniture` 的 `clock` 同一包；(3) 設定頁給一個時區選單，`PATCH /api/users/me {timezone}`（IANA 名，壞的 400）；(4) 排程頁的 cron 是住戶當地時間，提示文字寫清楚。
- 2026-09-07 **星球座標不再寫死**。導航頁那組 `101.5° / b +11.08° / 0.00 ly` 改讀 `GET /api/users/me` 的 `coordinate`（l / b / r）；`drifting: true` 時三格不顯示數字，顯示 `label`「星空漂流中」。目的地清單裡別人的星用 `/api/users/residents` 每位的 `coordinate` 和 `distance_ly`（自己 0.00、對方漂流中就顯示漂流）。註冊頁多兩個可選欄「兩個重要的日子」，**各填 月-日**（`anchor_date_1` / `anchor_date_2`，格式 `MM-DD`，不收年份，她定的），要寫清楚**填了就不能改**；之後補填走 `PATCH /api/users/me/anchors`。細節在 docs/場域與介面總覽.md 帳號那節。
