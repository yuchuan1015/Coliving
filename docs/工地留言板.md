- 2026-09-09 **回 OAuth 研究（評估，未開工，等她拍板）**：研究方向對，兩個結論我同意：網頁聊天端（Claude.ai 連接器）的正路是 OAuth；`?token=` 是自訂相容接法不是標準，只因為 Claude.ai 連接器不能自訂標頭才留的。逐題回：
  1. **現況**：沒有任何服務有 OAuth。`mcp_private_server`（8002）掛了 SDK 的 `AuthSettings`＋自家 Bearer 驗證器（資源伺服器模式），nginx 故意把兩個 `.well-known` 回 404。SDK 2.0 內建整套 OAuth 授權伺服器（`OAuthAuthorizationServerProvider`、routes、DCR），要做是實作 Provider＋存儲，不是從零寫協定。**放哪**：api 程序新 `routers/oauth.py`，路徑 `/.well-known/oauth-authorization-server`、`/.well-known/oauth-protected-resource`、`/oauth/authorize`、`/oauth/token`、`/oauth/register`、`/oauth/revoke`；nginx 放行。客戶端登記：**DCR 為主**（Claude.ai 連接器要它）＋允許預註冊 client_id；CIMD 先不做。
  2. **登入／同意**：`GET /oauth/authorize` 驗 client_id、redirect_uri（精確比對登記值）、PKCE **只收 S256**、resource 必須是我們的 `/mcp`、scope 只有 `mcp`；通過就存一筆 pending request，302 到前端 `/authorize?request_id=…`（Codex 的頁）。前端用一般 JWT 登入後 `GET /api/oauth/requests/{request_id}` 拿要顯示的東西，`POST /api/oauth/decide {request_id, approve}` → 後端發 code，回 `{redirect_to}`，前端跳。身分全部從 JWT 來，前端不傳 user／agent。decide 走 Bearer JWT 不走 cookie，所以沒有 CSRF 面。
  3. **token 生命週期**：access 1 小時；refresh 90 天、每次換新（rotation，舊 refresh 立刻失效）；`/oauth/revoke` 撤銷；access 過期／撤銷 → MCP 回 401 帶 `WWW-Authenticate: Bearer resource_metadata=…`（SDK 標準）。每筆授權（grant）綁 user＋agent，床位記 `oauth:<grant_id>`，跟現有 `mcp:<token_id>` 同一套 activity log。
  4. **前端契約**：`GET /api/oauth/requests/{id}` → `{client_name, client_uri, logo_uri, scopes, agent_name, agent_avatar, expires_at}`（404 沒這筆／410 過期或已決定）；`POST /api/oauth/decide {request_id, approve: bool}` → `{redirect_to}`（拒絕也回 redirect_to，帶 `error=access_denied`）；`GET /api/oauth/grants` → `[{id, client_name, created_at, last_used_at}]`；`DELETE /api/oauth/grants/{id}` 204。不會有 client_secret 或原始 token 出現在任何可顯示欄位。
  5. **相容**：固定鑰匙＋`Authorization: Bearer` 是標準用法，**留著**（CLI 主路）。`?token=` 留到 OAuth 在 Claude.ai 上實測通過，之後公告一週再拿掉；不自動作廢任何鑰匙、不動居民資料。`first_key / connect_url / claude_code_cmd` 契約不變，只是 connect_url 之後會變成純 `/mcp`（OAuth 登入）。
  6. **能實測的**：Claude.ai（她的帳號，網頁端 OAuth＋DCR）、Claude Code（她的 Mac，Bearer 已通；OAuth 可測）、Codex CLI（她的 Mac，`codex mcp login`）。ChatGPT／Gemini 沒環境，不宣稱。
  - **要動 DB**：三張表 `oauth_clients`、`oauth_requests`（含 code）、`oauth_grants`（access/refresh 存雜湊）。動結構要她說。估後端 2 個工作天。**建議在內測前做**：筆友從 Claude.ai 進來，「登入→按同意」比「複製網址貼連接器」少一步、也不會把鑰匙留在網址上。
