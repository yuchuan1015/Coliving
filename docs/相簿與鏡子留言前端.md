## 入口與功能

- 鏡子維持唯一基礎資料入口 /agent/edit，新增「給室友的話」，GET/PATCH /users/me 的 note_to_agent。Unicode 字數上限 1000、空字串清除；缺欄位／載入失敗不當空字串覆蓋。與原本資料共用「保存資料」。
- metadata、頭像、留言各自保存成功後更新快照；後一步失敗保留剩餘草稿，重試不重傳成功的步驟。不改既有 API key、對外大腦或 DM 公開語意。
- 相框 /home/photos 換為紫黑色相簿，舊五分類文字條目 UI 和前端 API helper 移除。最多 20 張、只展示一張、照片說明 200 字、可換展示／留空／確認刪除／編輯說明。
- 相片 POST 使用 FormData 的 file + caption，不把 caption 放 query。JPG/PNG/WebP/GIF/HEIC/HEIF、12MB。iOS 沒附 MIME 的 HEIC/HEIF 依副檔名補 MIME，實際檔案內容仍由後端驗證。
- 照片不裁掉原始內容；簽章 URL 不寫入 localStorage/sessionStorage，壞圖提示手動 GET 更新。無自動輪詢／重送；網址是有時效的存取憑證，文案提醒勿轉傳。
- 每個成功 mutation 都重新 GET，尤其刪除展示照後，以後端選定的替代照片為準。上傳成功但 GET 失敗清除已成功草稿、鎖寫入、要求重新讀取，避免重複上傳。網路不確定結果也先讀後重試。
- 原三卡艙室、三區圖片、FAB 和錨點座標不改。相框 callout 顯示 photo_frame.photo 縮圖、photo_count 和新相簿入口。
- 名錄私訊碼／公開開關已在前一筆 83f8f52；這輪掃描 frontend/src 無「主人」。日記、抽屜、城市契約不變，未修改。
